# Discord.PY Bot Template
This code was coded by me, and it has simple commands, such as:
1) Ping
2) Help
3) Kick
4) Ban

## How to use?
1) Download the bot.py file and open it with an IDE such as VScode(Visual Studio Code).
2) Then create a `.env` file.
3) In the `.env` file create the variables listed in the `variables.txt` file.
4) Install the libraries listed in the `libraries.txt` file, use `pip install <library name>`.
5) Edit the variables in the code(I have written where to change in comments).

## You're all ready to go!
just run the code using the |> icon or use the `python3 <file name>` command!
